# Bundled board themes

These are board/stone adaptations, not execution of Sabaki theme CSS or ASAR packages.

- BadukTV: https://github.com/upsided/upsided-sabaki-themes — MIT. Board, stones and surrounding background from the BadukTV pack.
- Photorealistic: https://github.com/SabakiHQ/theme-photorealistic — CC0. Stone images. Since this theme provides no board texture, the board uses SabakiHQ/shudan css/board.png (MIT; BOARD-LICENSE.txt).
- Subdued: https://github.com/fohristiwhirl/sabaki_subdued_theme_40 — MIT. Board and stone images.

Each directory retains its upstream license and CSS for attribution/reference. sources.json records pinned upstream URLs and SHA256 checksums. The UI offers a classic fallback and stores the chosen skin separately from engine preferences. Assets are bundled for offline use.
