# 局面训练

导入 SGF 后，在复盘区选择「局面训练」，点击「提取训练局面」。结果按中盘与后盘的问题段生成卡片，每张卡片显示起点小棋盘；点击「开始训练」后，执起点的行棋方与 KataGo 续弈。普通入口不要求填写阈值、搜索量或候选坐标；原容错分析保留在折叠的「高级分析与设置」中。

## 引擎准备与结果恢复

训练提取与续弈默认在后台调用 SSH 远端；本次用户环境配置为 waffle。`tolerance-review/training-config.json` 独立保存训练默认设置，首次使用可从已有有效 SSH 容错配置迁移。高级分析保存本地设置不会覆盖该默认值；缺少远端配置或 SSH 路线时明确报错，不自动转本地或下载模型。私有主机、模型与引擎路径仅保存在用户应用数据中。

已保存远端训练默认值时，启动应用不会自动启动本地前景引擎。提取仍使用现有 Batch 独占槽，开始前暂停前景任务，完成后不自动恢复前景计算；后台执行表示窗口可显示进度和取消，不表示与前景引擎同时计算。SSH 的 HumanSL 模型必须已部署到目标机。智子云尚未提供经过验证的完整 HumanSL 响应，不能用于提取。

提取冻结原谱全文与设置，扫描主线中的中盘与后盘，再加深预算内的重点局面。粗扫优先补搜未评价的实战走法（受每局面补搜上限约束）；全盘加深优先级综合实战目损失、胜率损失与已知非安全质量。默认使用现有分析预算，不要求普通用户配置。结果、模型指纹、缓存和取消后的部分结果沿用 [容错任务生命周期](tolerance-review.md)。重新打开完全相同的 SGF 可恢复最近报告并重新生成卡片。

取消、失败或中断的报告生成的卡片标为「暂存，未完成全盘提取」，运行中不能开始训练。完成报告没有符合条件的起点时明确显示为空。粗扫结果与已加深结果在识别依据中分开标识；有限预算下的筛选不是对整盘问题的完备证明。

## 问题段与起点

当前自动筛选策略位于 [training.ts](../../apps/desktop/src/domain/tolerance/training.ts)：

- 19 路棋跳过前 60 手，只选第 61 手及以后的决策；第 161 手开始标为后盘。较小棋盘按面积比例缩放手数界限。开局在粗扫之前过滤，旧全盘报告也在归并之前过滤，因此开局问题不会用作中盘问题段的起点。短棋谱可能没有训练局面。
- 实战损失至少 3 目，或至少 10 个胜率百分点；或者当前方仍有至少 10% 胜率，且「胜率损失 ≤ 5pp 的已知概率 + 全部未知概率」不超过 40%。未知落点全部可能安全，因此缺少搜索本身不能触发低容错。
- 按黑白分别合并，相邻问题点相隔不超过 8 手、整段跨度不超过 20 手。中间连续三次己方决策的已知安全概率达到 80%，结束旧段；单个较容易局面不会把一套问题拆开。长间隔、持续恢复、不同执棋方或超出跨度另建起点。
- 每段只取第一个识别点**落子之前**的节点。例如 131、133、135、139、141 手属于同一段时，只生成第 130 手结束后的起点；137 手暂时容易不会额外生成卡片。

每张卡片的小棋盘还原首次识别点落子前的局面，标记最后一手，显示该方行棋；不显示候选、后续走子或变化提示。原生预览按 SGF 节点精确回放；浏览器测试页按主线手数回放，仅用于显示验证。手数分界是筛选规则，不保证每个残局都棋子密集。

这些常数是首版产品默认策略，用户不需设置。卡片的「识别依据」列出实际检查的手数和走法；低容错与实战损失是观察依据，不将相邻关系直接解释为较早走法导致后面的失误。

## 训练副本与续弈

开始训练时，后端复制从根到起点的唯一祖先链，保留规则、贴目、让子摆子、初始行棋方、停一手及完整走子历史，移除所有后续走子、其他分支、结果、评论和标记。删除程序标记前将旧定点格式贴目写为解析后的标准值，避免副本贴目改变。不会用仅含当前棋子的快照替代历史。副本的棋谱树没有原谱未来，训练期间隐藏候选、策略、归属、走势和测评提示。

续弈使用已保存的远端训练默认设置，默认标准 KataGo、每手 800 次访问与 3 秒搜索上限。引擎准备、连接和退出耗时不包含在 3 秒内；当前每次 AI 应手独立启动并关闭 analysis 会话，避免依赖另行连接的 GTP 会话，代价是每手有模型加载和 SSH 连接开销。请求保留完整历史并校对请求 ID、手数、行棋方，所有返回落点经 SGF 规则校验。旧请求不会应用到新对局；取消等待 worker 回收和退出确认后返回。每手使用 Batch 独占槽，退出应用取消训练请求；退出未确认时显示错误，不自动恢复前景连接。

「结束训练，返回原谱」恢复原文、选中节点、原文件路径和是否未保存；训练走子另留副本，可在训练面板点击「另存上次训练棋谱」。训练期间可点击「另存训练棋谱」，只保存新副本，不覆盖原文件。返回时建立新的编辑历史，原文本中的未保存修改仍保留，但原会话撤销栈不跨训练恢复。上次训练副本保留在当前应用会话内，需另存才能跨重启保留。
