## 当前检查

- 发布配置：窗口标题契约与现有 `lizze-remake` 对齐，保留 bundle/product 名称；新增标题漂移拒绝测试。
- Windows 工作流：更新 Actions 主版本，只生成三种安装包的 Actions 产物，删除针对旧 release 的自动覆盖上传。
- 首次 Linux CI 检出 macOS 专用钥匙串常量及代理解析函数的非 macOS dead-code；补齐精确 cfg 边界后重跑，不降低全局 warnings 检查。
- Rust：格式与严格 Clippy 检查通过；测试专用包装器按 cfg(test) 隔离，第三方固定回调类型及现有 IPC 参数使用局部 lint 说明。
- Python 测试 282 项通过；发布资源检查 4 项通过，workflow 与 scaffold 契约检查通过。
- 前端测试：106 通过、1 个私密完整棋谱对照测试因未指定本机夹具而跳过。此前显式指定仓库外夹具的 107 项已通过；测试源码不包含这些棋谱。
- 完整 Rust workspace 回归已执行，无失败；外部环境测试保持 ignored，不算入通过。
- HumanSL 40 的四方数值对照和 12 手真实引擎补算范围见 [模块说明](../engine/humansl40-strength.md)。

## 保留限制

`smoke_user_flows.py --verbose` 本轮仍为 43 通过、5 失败，与整理前的中文界面/英文文案断言失配相同。
五项为 `sgf_annotation_surface`、`legacy_config_migration_surface`、`runtime_asset_layout_surface`、`legacy_import_capture_helper_surface`、`katago_review_workflow_ux_smoke`。
未删除失败断言，也不把历史证据当成新原生 GUI 验收。

本轮 HumanSL 40 原生窗口自动化超时，尚未完成完整点击/截图验收。
Windows 构建/安装包生成不等于真机安装、卸载、GPU 分析及 HumanSL GUI 验收。
macOS 不做 Developer ID 签名或公证，Windows 不做 Authenticode 签名；GitHub 正式/latest 状态不改变这些限制。
参考模型来自固定训练协议，复用其他网络/计算量可能带来输入分布偏移，保留实验标识。

## 私密边界

提交仅包含公开程序、模型工件、合成/脱敏回归夹具和维护文档。
本轮私密棋谱、私有标签与训练数据、完整参考分析、账号状态、SSH 路线与本机 QA 目录不纳入提交或安装包。
此前已公开的开发证据维持既有范围；新增真实验收只公开去路径/凭据后的摘要和已核对的界面图。
