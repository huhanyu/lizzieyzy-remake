## 迁移与拆分约束

以 Java 的 ZhiziApiClient、ZhiziGtpTransport、RemoteComputeConfig 为协议依据，迁移必要行为，不照搬重复接口和旧界面架构。

| 职责 | 归属 | 边界 |
| --- | --- | --- |
| 登录、令牌、VIP 分配 | src-tauri/src/zhizi.rs | 不处理棋谱、帧解析与界面 |
| Socket.IO 与 GTP 字节传输 | crates/zhizi-socketio | 不分配算力、不管理账号、不理解棋局 |
| 登录与连接界面 | components/CloudComputePanel.tsx | 不保存密码或令牌、不直接访问云服务 |
| 实时分析会话 | 从现有 lib.rs 按职责提取的模块 | 本地与云端共用重放、任务互斥和过期帧拦截 |
| 应用装配 | lib.rs 与 App.tsx | 只注册命令、连接状态及组合组件，避免继续承载协议实现 |

每次提取先保留现有行为并运行相关回归，再接入新能力。不要为尚未接入的其他云厂商建立通用插件框架。重点验收：分支与让子局面一致、胜率视角明确、旧帧不覆盖新局面、断开后释放任务、登录不自动分配云会话。
